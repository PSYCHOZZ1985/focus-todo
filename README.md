# Фокус — список задач

Небольшое веб-приложение на HTML, CSS и JavaScript без сборки и внешних зависимостей.

[Открыть сайт](https://psychozz1985.github.io/focus-todo/)

- Добавление задач через кнопку или Enter.
- Отметка выполнения и возврат задачи в работу.
- Удаление задач.
- Сохранение текста и состояния задач в `localStorage` после обновления страницы.
- Фильтры «Все», «В работе», «Готово», счётчик и адаптация для телефона.
- Управление с клавиатуры, подписи для экранного диктора, проверка пустого ввода.

## Запуск

Откройте опубликованный сайт или запустите локальный статический сервер в папке проекта:

```sh
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Хранение данных

Задачи хранятся только в текущем браузере и профиле под ключом `focus-todo:v1`. Сервер и учётная запись не нужны. Список не синхронизируется между устройствами. Очистка данных сайта удалит сохранённые задачи; в приватном режиме браузер может удалить их при закрытии сеанса.

Другие вкладки этого сайта получают изменения через событие `storage`. При одновременной записи действует последний сохранённый список; совместное редактирование с объединением изменений не предусмотрено.

При запрете записи или заполненном хранилище появляется предупреждение. При повреждённых данных приложение не перезаписывает старый список: новые задачи остаются в памяти вкладки. Для начала с чистого списка можно удалить данные этого сайта в настройках браузера. У одной задачи ограничение 200 единиц UTF-16 (эмодзи могут занимать две).

## Проверка основных функций

1. Введите две задачи: первую добавьте через Enter, вторую кнопкой «Добавить». Они появятся в порядке ввода.
2. Отметьте первую задачу: появятся галочка и зачёркивание. Повторное нажатие вернёт её в работу; фильтры покажут соответствующие задачи.
3. Удалите вторую задачу кнопкой с корзиной: она исчезнет, счётчик обновится.
4. Обновите страницу: первая задача и её отметка сохранятся, удалённая задача не вернётся.

Пустые и пробельные строки не добавляются. HTML отображается обычным текстом. Все действия доступны с клавиатуры: Tab для перехода, Enter для кнопок и добавления, Space для отметки выполнения.

## AI-инструмент

Для реализации использован OpenAI Codex: подготовка HTML/CSS/JavaScript, проверка сценариев и исправление замечаний. Результат проверен в браузере: добавление, выполнение, удаление и восстановление списка после обновления.

Файлы проекта: `index.html` — разметка, `styles.css` — адаптивное оформление, `app.js` — логика и сохранение. Для GitHub Pages используется ветка `main`, корневая папка и файл `.nojekyll`.
